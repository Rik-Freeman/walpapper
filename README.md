# 🎨 Семантическое приложение для обоев

Автоматическая смена обоев и заставки экрана блокировки с использованием Windows API и семантического подхода.

## ✨ Возможности

- 🤖 **Автоматические триггеры** - обои меняются при включении, входе в систему, выходе из сна
- 🔒 **Смена заставки** - заставка экрана блокировки меняется вместе с обоями
- 🧠 **Умные рекомендации** - учитывается время суток
- 📚 **Большая библиотека** - скачивание из Picsum Photos и akspic.ru
- 🖱️ **Контекстное меню** - быстрая смена через правую кнопку мыши
- 🔇 **Тихий режим** - без уведомлений и окон консоли

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Скачивание обоев

```bash
python expand_wallpaper_library.py
```

Выберите источник (рекомендуется Picsum Photos) и количество обоев.

### 3. Установка автоматических триггеров

```bash
python setup_auto_trigger_ps.py
```

Выберите опцию `1` → Установить триггер

**Готово!** Обои будут меняться автоматически при:
- Включении компьютера
- Входе в систему
- Выходе из режима сна

### 4. Контекстное меню (опционально)

```bash
python context_menu_installer.py
```

Добавляет пункт в меню правой кнопки мыши на рабочем столе.

## 📖 Использование

### Автоматический режим (рекомендуется)

После установки триггера обои меняются автоматически. Никаких действий не требуется!

### Ручная смена через контекстное меню

1. Правая кнопка мыши на рабочем столе
2. Выбрать "🎨 Сменить обои и заставку"

### Через приложение

```bash
python semantic_wallpaper_offline.py
```

Интерактивное меню с опциями:
- Получить рекомендации
- Сменить обои и заставку
- Расширить библиотеку
- Статистика

---

## 🎯 Умные рекомендации

Система учитывает время суток:

- 🌅 **Утро (6-12)** → природа, пейзажи, минимализм
- ☀️ **День (12-18)** → город, абстракция
- 🌆 **Вечер (18-22)** → закаты, природа
- 🌙 **Ночь (22-6)** → минимализм, абстракция

## 🔧 Управление

### Расширить библиотеку

```bash
python expand_wallpaper_library.py
```

### Управление библиотекой

```bash
python manage_library.py
```

Показывает статистику и позволяет очистить кэш.

### Настройка триггеров

```bash
python setup_auto_trigger_ps.py
```

Опции:
- Переустановить триггер
- Удалить триггер
- Протестировать (запустить сейчас)

### Триггер по расписанию

```bash
python setup_scheduled_trigger.py
```

Обои будут меняться каждые N часов.

## ⚙️ Технологии

- **Windows Task Scheduler API** - автоматические триггеры
- **Windows Registry API** - контекстное меню, заставка
- **SystemParametersInfoW** - смена обоев
- **NetworkX** - граф знаний
- **PIL/Pillow** - обработка изображений

## 🐛 Устранение проблем

### Обои не меняются автоматически

Проверьте триггер:
```bash
python setup_auto_trigger_ps.py
```

Выберите опцию `3` → Протестировать

### Заставка не меняется

Запустите от имени администратора:
```bash
# Правая кнопка на PowerShell → Запуск от имени администратора
python setup_auto_trigger_ps.py
```

### Контекстное меню не работает

Перезапустите Explorer:
- Ctrl+Shift+Esc → Диспетчер задач
- Найдите "Проводник" → Перезапустить
